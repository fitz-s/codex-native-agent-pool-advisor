Native Agent Admission Guard

Read-only native child admission for explicit model and effort routing.

Boundaries

Codex runtime owns child lifecycle and SQLite state. This guard reads current-parent native edges only when a real PreToolUse event exists. It never repairs, archives, resets, or closes a child.

Routing

Choose Luna, Terra, or Sol and reasoning effort for each task. Roles do not select or restrict either value.

Verification

Use npm test, node scripts/doctor.mjs, and the read-only scripts/live-check.mjs against a real transcript.
